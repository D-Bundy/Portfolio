About Me

This portfolio showcases the projects I have made within both Unity and Unreal Engine. These projects have been developed during my time at Edge Hill University, where I studied Games Programming. The prototypes displayed within this portfolio demonstate the skills and knowledge I have gained throughout my studies.

Projects

Final Year Project - Developed in Unity

A first-person shooter, which focuses on the implementation of AI, to improve the players’ experience within the game. Features procedural content generation, creating a unique maze for the player to explore on each playthrough. Additionally, the game utilises behaviour trees to alter enemy interactions, dependent on the players’ actions. This game also uses an AI director, which controls the pacing of the game by altering the enemy spawn rate. This project showcases my ability to create adaptive game systems that respond to player behaviour, aiming to increase both replayability and engagement.

Parkour Simulator - Neon Trials - Developed in Unity

A parkour-based time trial game where the player competes to achieve the fastest completion time for each level. Each level is generated procedurally, and with each completion the length of the level will increase, heightening the difficulty. This project showcases my ability to develop and implement procedural generation systems alongside smooth movement mechanics. Furthermore, it demonstrates my understanding and ability to create a scalable game within Unity. This prototype is controller compatible.

Classed Based FPS - Developed in Unreal Engine

A class-based first-person shooter in which the player can select one of three different characters, each with their own attributes and playstyles. The classes available are Tank, Stealth and Assault. Each class alters the player’s movement speed, height, hitbox, weapon damage and maximum health. This project showcases my ability to deploy effective and balanced gameplay mechanics, allowing users to play the game in their own style. Additionally, this project demonstrates my versatility, being able to produce in Unreal Engine alongside Unity.
